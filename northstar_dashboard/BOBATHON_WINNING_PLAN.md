### Technical Pitfalls
- ❌ Overengineering - Keep it simple
- ❌ Scope creep - Stick to the plan
- ❌ No error handling - Always handle failures
- ❌ Hardcoded values - Use configuration
- ❌ No testing - Test as you build
- ❌ Last-minute integration - Integrate early

### Documentation Pitfalls
- ❌ Forgetting to document Bob prompts
- ❌ Vague problem statement
- ❌ Missing README sections
- ❌ No architecture diagrams
- ❌ Poor code comments

### Demo Pitfalls
- ❌ Too long (>5 minutes)
- ❌ Too technical (lose the audience)
- ❌ No story (just feature list)
- ❌ Live demo fails (always have backup)
- ❌ Poor audio quality
- ❌ No captions

### Submission Pitfalls
- ❌ Missing required files
- ❌ Wrong branch name format
- ❌ Incorrect folder structure
- ❌ Video not uploaded to Box
- ❌ PR description incomplete
- ❌ Submitting at last minute
